# Melanie Events

Projektgrund med React, TypeScript och Vite.

## Kom igång

```sh
npm install
npm run dev
```

Öppna den lokala adressen som visas i terminalen.

## Kommandon

- `npm run dev` – starta utvecklingsservern.
- `npm run build` – kontrollera TypeScript och bygg för produktion till `dist/`.
- `npm run lint` – kontrollera koden med ESLint.
- `npm run preview` – förhandsvisa produktionsbygget efter `npm run build`.

## Filer

- `src/App.tsx` – startsidan.
- `src/App.css` – startsidans stilar.
- `src/index.css` – globala stilar.
- `src/main.tsx` – appens startpunkt.

TypeScript körs i strikt läge. Projektet innehåller än så länge en statisk startsida.
